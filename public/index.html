아이디어에서 오디오까지

MIDI 트랙을 만들고 피아노롤의 빈 칸을 눌러 노트를 추가하세요. 노트를 드래그하거나 Inspector에서 음높이·시작·길이·벨로시티를 정확히 편집할 수 있습니다.

  • Space 재생 / 정지, Delete 선택 노트 삭제
  • ⌘/Ctrl Z 실행 취소, ⌘/Ctrl Shift Z 다시 실행
  • 편집은 자동 저장됩니다. 연결된 CLI 변경도 화면에 즉시 반영됩니다.
  • 재생은 현재 프로젝트를 렌더한 오디오입니다. 편집하면 이전 재생은 멈춥니다.
  • MIDI 내보내기는 노트·템포·박자·트랙 이름·마커 시작 위치를 보존합니다. 사이클 마커의 끝과 프로젝트 마커 ID는 SMF에 보존하지 않습니다. 오디오·믹서 설정·악기 소리·뮤트/솔로 상태는 포함하지 않습니다.
  • Shift/⌘/Ctrl + 노트 클릭은 다중 선택, 피아노롤에서 ⌘/Ctrl A는 전체 선택입니다. MIDI 도구에서 선택 노트 또는 클립 전체를 처리합니다.
  • Shift/⌘/Ctrl + 클립 클릭으로 여러 클립을 선택합니다. 타임라인 ⌘/Ctrl 드래그는 독립 복사, Alt/Option은 스냅 해제, Shift는 이동 축 제한입니다. 선택한 뒤 미디어 풀에서 대응 원본을 찾습니다. 클립 편집과 Inspector는 포커스한 한 클립에 적용합니다.
  • 프로젝트 JSON은 WAV의 상대 경로를 참조합니다. 미디어 포함 보관에는 백업 ZIP을 사용하세요.

MIDI 도구

노트 내부를 지나는 위치만 분할합니다. 원래 시작·끝 위치는 바꾸지 않으며 컨트롤러는 이동하지 않습니다.

선택한 각 노트를 같은 채널·음높이의 다음 노트와 붙입니다. 다음 노트는 선택하지 않아도 흡수됩니다. 첫 노트 속성을 유지하며 컨트롤러는 이동하지 않습니다.

클립 시작을 기준으로 정렬합니다. 원래 타이밍 모드는 그리드를 바꿔도 처음 저장한 타이밍부터 계산합니다. 현재 타이밍 모드는 강도만큼 반복해서 그리드에 접근합니다. 스윙은 홀수 그리드를 늦춥니다.

저장한 퀀타이즈 전 시작·길이로 되돌립니다. 음높이·벨로시티 편집은 유지됩니다. 수동 타이밍 변경이나 레가토로 기준이 해제된 노트는 그대로 둡니다.

현재 시작·길이를 새로운 원래 타이밍으로 확정합니다. 이후 퀀타이즈 원복은 이 시점으로 돌아옵니다. 실행 취소로 이전 기준을 되살릴 수 있습니다.

반음 이동→현재 스케일 최근접음(동률 위)→같은 음 수면 도수 대응, 다르면 목표 최근접음→음역 제한 순서입니다. 루트는 가장 가까운 반음 방향으로 이동합니다.

같은 음 이름을 유지해 음역에 넣습니다. 너무 좁은 음역은 가까운 옥타브 후보를 경계에서 제한하고, 최저=최고면 모든 대상 노트를 그 음으로 맞춥니다.

버튼은 전조 값을 지정합니다. 적용 시 노트 원본 음높이를 변경합니다. 선택 클립 범위는 창을 열 때 고정하며 오디오 클립은 제외합니다. 음역 옵션을 끄면 MIDI 0–127 범위를 벗어나는 노트가 있을 때 묶음 전체를 취소합니다.

선택 노트의 시간 범위를 기준으로 반전합니다. 음높이·노트 길이·벨로시티는 유지하며 컨트롤러는 이동하지 않습니다.

선택 노트를 페달 해제까지 늘리고 이 파트의 모든 Sustain(CC64) 이벤트를 제거합니다. 선택하지 않은 노트의 재생도 달라질 수 있습니다. 파트 밖 페달 상태는 사용하지 않으며 끝까지 눌린 페달은 파트 끝에서 해제한 것으로 처리합니다.

선택 범위 안에서 겹친 노트를 다음 노트 시작까지 줄입니다. 같은 시각에 시작하면 저장 순서상 마지막 노트를 남기고 앞 노트 길이는 0으로 줄입니다. 노트 ID와 벨로시티는 유지합니다.

노트 시작은 유지합니다. 결과는 최소 1 tick이며 길이가 바뀐 노트의 퀀타이즈 원복 기준은 해제됩니다.

정리 시 노트는 연결된 발음 구간별로 나누며, 컨트롤러·곡선은 별도 Controls 파트에 원래 위치로 보존합니다. 음원 release·페달은 무음 판정에 포함하지 않습니다.

원본 트랙별로 새 트랙에 복사하고 원본 파트는 뮤트합니다. 오디오·SysEx/meta는 분리 기준과 구분합니다. SysEx/meta는 Common 트랙으로, 음높이 모드의 채널 제어는 해당 채널의 음높이 트랙마다 복사합니다. 외부 라우팅·setup 메시지·무작위 modifier를 확인하세요. Lane 분리는 아직 지원하지 않습니다.

파트 끝보다 앞에 끝나는 구간을 지정하세요. 루프 뒤 기존 노트·이벤트를 반복본으로 교체합니다. 마지막 노트는 파트 끝에서 자릅니다. 곡선은 파트 전체에서 정수 tick MIDI 점으로 변환되며 Undo로 복구합니다. 컨트롤러 chase와 독립 재생 루프 설정은 적용하지 않습니다.

파트 전체의 일반 CC에 적용합니다. 각 구간의 처음·끝, 같은 tick, 곡선, 짝이 있는 14bit CC, 스위치·Bank·RPN/NRPN·Data Entry·채널모드 CC는 보존합니다. 프로그램·채널모드·SysEx 경계를 넘겨 줄이지 않습니다. 오차는 원래 계단형 값과 비교하며 선형 곡선 오차와 다릅니다.

오래 시작한 노트부터 다음 시작까지 줄입니다. 같은 시점은 저장 순서로 결정하며 길이 0이 될 수 있습니다. 선택 노트 범위에서는 미선택 노트를 계산하지 않습니다. 페달·음원 release tail은 계산하지 않습니다.

파트 전체·모든 채널에 적용합니다. 노트·피치벤드·프레셔·프로그램·SysEx는 보존합니다. CC 곡선도 제거됩니다. 실행 취소할 수 있습니다. 사용자 지정 스위치형 CC는 자동 판별하지 않습니다.

결과를 반올림한 뒤 지정 범위로 제한합니다. 노트 온은 1–127, 노트 오프는 0–127입니다. 오프 값이 0보다 크면 실제 Note Off 메시지로 보존합니다.

같은 채널의 다음 노트까지 연결합니다. 양수는 겹침, 음수는 틈이며 마지막 노트는 클립 끝을 기준으로 합니다.

이 작업은 클립 전체의 같은 채널·음높이·시작 위치 중복을 제거합니다. 먼저 저장된 노트를 유지합니다.

미디어 풀

원본 WAV의 사용 수·누락·내용 변경을 검사합니다. 프로젝트와 미디어를 함께 보관하려면 상단의 백업 ZIP을 사용하세요.

누락·변경된 WAV는 동일한 원본 파일을 선택해 복구합니다. 변경된 파일은 별도로 보존하며, 다른 연주로 대체하지 않습니다.

편집 이력

경계를 왼쪽으로 옮기면 실행취소, 오른쪽은 다시 실행합니다. 실행취소 후 새 편집을 하면 뒤쪽 분기는 사라집니다.

한도를 줄이면 오래된 이력이 제거됩니다. 큰 프로젝트는 이력 파일 용량 한도에 따라 단계가 더 적게 보관될 수 있습니다.

자동백업

프로젝트 편집은 즉시 저장됩니다. 자동백업은 지정한 간격으로 변경된 프로젝트의 이전 시점을 별도로 보관합니다. WAV 원본은 포함하지 않으므로 미디어 포함 보관에는 백업 ZIP을 사용하세요.

한도를 넘으면 이 프로젝트가 만든 가장 오래된 자동백업부터 교체합니다. 내려받은 JSON을 옮길 때는 assets 폴더도 함께 보관하세요. CLI recover-backup은 새 프로젝트로 복구하며 필요한 원본을 수집할 수 있습니다.

MIDI 프로젝트 설정
추출한 첫 이벤트를 파트에서 제거하고 같은 채널의 시작 설정으로 옮깁니다. 여러 채널 값은 남기고 보고합니다. Inspector 시작 설정은 파트 삽입 위치와 관계없이 프로젝트 0 tick에 출력합니다. 오디오 믹서 gain/pan으로 변환하지 않습니다.

템포 교체는 삽입 위치 이후를 파일 템포로 바꾸며 기존 클립의 초 단위 재생 위치에 영향을 줍니다. 초기 박자 적용은 삽입 위치와 관계없이 프로젝트 전체에 적용합니다. 중간 박자 변화는 아직 적용하지 않으며 가져오기 결과에 기록합니다. 여러 MIDI 파일의 교체 옵션은 파일마다 적용됩니다. 이 MIDI 설정은 타임라인 파일 드롭에도 적용됩니다. 단일 파트와 채널 자동 분해는 함께 선택할 수 없습니다.

새 트랙 대상이면 같은 위치 모드에서 파일마다 트랙을 만듭니다. MIDI는 지정한 MIDI 삽입 위치에 새 트랙으로 가져옵니다. 타임라인에 놓아 가져올 수도 있습니다. Shift는 이어붙이기, Alt는 위치 스냅 해제입니다. 최대 32개이며 파일마다 별도로 적용·Undo합니다. 중단·실패해도 앞서 가져온 파일은 유지됩니다.

MIDI 파일 내보내기

SMF는 편집 가능한 MIDI를 담습니다. 오디오·음원 패치 상태·믹서·뮤트/솔로는 프로젝트 파일로 보관하세요.

MIDI 옵션파트 안의 CC·Program은 별도 원본 데이터로 보존합니다. 믹서 오디오 gain/pan은 변환하지 않습니다. MIDI insert·트랙 자동화 Read는 아직 지원하지 않습니다.

Locator 출력은 0번 tick부터 시작하고 끝에서 노트·페달을 종료합니다. 낮은 PPQ는 짧은 노트와 미세 타이밍을 반올림할 수 있습니다.

오디오 내보내기

현재 프로젝트에 형식만 저장합니다. 출력 대상·구간·경로는 포함하지 않습니다.

지정 트랙 출력은 솔로 격리를 우회합니다. 직접 설정한 뮤트·트랙 게인/팬·마스터 게인은 유지하며 전체 프로젝트 길이를 기준으로 정렬합니다.

프로젝트·원본은 바꾸지 않습니다. 완료 후 Inspector에서 결과 파일을 내려받을 수 있습니다. 정수 PCM에서는 TPDF 디더링을 선택할 수 있습니다.

선택 클립을 트랙으로 이동

클립 시작·길이·내부 내용은 유지합니다. 대상 트랙의 악기·믹서·MIDI 출력 설정으로 재생됩니다. 여러 종류의 클립은 함께 옮길 수 없습니다.

선택 클립 묶음 반복

박자 기준은 상대 tick 위치, 시간 기준은 상대 sample 위치를 유지합니다. 시간 기준의 MIDI 시작은 가장 가까운 tick으로 반올림합니다. MIDI 내부 tick과 오디오 길이는 유지하므로 템포 변화에 걸친 MIDI의 초 단위 길이는 달라질 수 있습니다. 원본 미디어는 공유하고 MIDI는 독립 복사합니다.
