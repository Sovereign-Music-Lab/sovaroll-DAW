# 개발 노트 — Sovereign DAW / SovaRoll

[English](DEVELOPMENT.en.md) · [철학](../PHILOSOPHY.ko.md) · [기능 인벤터리](FEATURE_INVENTORY.ko.md) · [검증 기록](VALIDATION.md)

## 개발 방향과 공개 범위

소버린 DAW는 프로급 오픈소스 DAW 개발 프로젝트입니다. 공개 코드 버전은 **0.129.0**이며 로컬 MIDI·오디오 엔진과 브라우저 화면을 제공합니다. 구현, 제품 테스트, 브라우저 검사, 아키텍처, 모듈 지도, 제품 수용 기준과 미완료 작업 큐를 함께 공개합니다. 실제 근거는 검증 기록에 남기며 로드맵을 이미 구현한 기능으로 표시하지 않습니다.

**Sovereign DAW**는 제품의 방향, **SovaRoll**은 프로젝트 이름, **sovaroll-DAW**는 저장소 이름입니다. 기존 `.newdaw.json` 파일과 `NEWDAW_*` 설정은 호환성을 유지합니다.

## 설계에서 선택한 것

| 결정 | 이유와 현재 영향 |
|---|---|
| 로컬 Node.js 서버·브라우저 GUI·CLI | 두 인터페이스가 같은 상태와 저장 경로를 사용하며 편집 동작을 공유 |
| 공통 명령 엔진 | 사람과 자동화 편집에 같은 검증·리비전 검사·일괄 처리·Undo/Redo 적용 |
| 편집 가능한 MIDI·비파괴 오디오 | 편집·렌더 뒤에도 음악적 선택과 원본 미디어를 보존 |
| 렌더 worker·스냅샷 프리뷰 | 특정 리비전을 렌더하고 오래된 결과를 거부; 준비 지연은 남아 있음 |
| 명시적 프로젝트·미디어 처리 | 열기·수집·복구·교체에 필요한 계획과 검증 제공 |
| 작은 작업을 위한 에이전트 하네스 | 필요한 부분만 읽고 실패를 복구하며 확인할 수 있는 근거를 남김 |
| 저장소별 독립 실행 | 기본 사용에 DeepChord·SovaFlow·LLM 설치가 필요하지 않음 |

[아키텍처](agent/ARCHITECTURE.md), [모듈·명령 지도](agent/CODEMAP.md), [CLI 전체 도움말](CLI.md)을 제공합니다.

다음은 구현 작업의 요약입니다. 모든 기능의 검증 깊이가 같다는 뜻은 아닙니다.

| v0.48–v0.78 | 벨로시티 커서, 반복, 클립보드·시간 붙여넣기, 키보드·선택, 로케이터, 분할 정책과 회귀 검사 |

## 남아 있는 작업

Audio Unit probe는 처리본 다운로드, Undo 가능한 편집 클립 가져오기, 명시적 미리 듣기와 렌더마다 fresh instance를 사용하는 native 오프라인 악기 MIDI 렌더를 지원합니다. 완전한 실시간 플러그인·악기 호스팅은 향후 작업입니다. T-060은 대화상자 버튼 행 overflow를 수정하고 선택 MIDI의 fresh-instance 악기 WAV 렌더·편집 클립 가져오기를 연결했습니다. 기존 GUI 스모크 64개는 native 작업 이전에 모두 통과했습니다. 실제 장치 결과는 [수동 체크리스트](agent/MANUAL_CHECKS.md)로 기록하고 근거는 [VALIDATION.md](VALIDATION.md)에 있습니다.

장기적으로 저지연 네이티브 오디오, 폭넓은 플러그인·악기, 악보, 심화 믹싱, 전체 이중 언어 UI, 접근성, 다양한 플랫폼·실제 장치 검증과 선택적 자율형 작곡 통합을 발전시킵니다.

## Gemma 4와 개발 근거

인계 이후 AI 코딩은 **로컬 Gemma 4만 사용**할 계획입니다. 하네스는 외부 코딩 런타임의 작업 범위와 근거를 관리하며 모델을 선택하거나 호스팅하지 않습니다. 이번 공개에서 Gemma 작업 실행을 주장하지 않습니다. 기존 제품 테스트의 검증 조건을 그대로 유지하고 공개 수용 기준 검사는 별도 자료 없이 작동합니다.

새 동작에는 의미 있는 테스트가 필요합니다. 공개 검증은 전체 제품 테스트, native 테스트, 첫 납품 브라우저 흐름, 공개 파일 검사와 새 소스 트리 실행을 포함합니다. 청음과 장치 지연은 수동 검증입니다. 실패는 기록하고 테스트를 약하게 바꿔 숨기지 않습니다.

## 전체 제품 구조

DeepChord는 로컬 LLM으로 Logic Pro를 사용하며 작곡합니다. Sovereign Flow / SovaFlow가 두 도구를 연결합니다.

**인간 → LLM(선택적 RAG·LoRA) → 소버린 DAW → 자율형 작곡 → Logic Pro MCP → 결과 → 인간 피드백 → 반복.**

각 도구는 자체 필수 기능과 설치 경로를 유지합니다. 어댑터로 연결할 수 있지만 연결이 없어도 DAW 편집·내보내기는 동작해야 합니다. 실제 연동은 지원 여부와 근거를 검증한 뒤 제공 기능으로 소개합니다.
