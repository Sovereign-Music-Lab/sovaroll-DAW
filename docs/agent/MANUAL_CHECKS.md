# 실제 장치 수동 검사 / Manual hardware checks

이 문서는 **사람이 실제 마이크·헤드폰·스피커로 수행하는 검사**입니다. 가짜 장치 E2E나 PCM 수치로 이 결과를 대신 채우지 마세요. 작업 전 프로젝트를 백업하고, 처음에는 낮은 음량과 헤드폰을 사용해 피드백을 방지하세요.

- 검사일 / Date:
- 검사자 / Tester:
- 마이크·입력 장치 / Input:
- 헤드폰·스피커 / Output:
- 프로젝트·버전 / Project and SovaRoll version:

| # | 검사 절차 / Procedure | 예상 결과 / Expected result | 실제 결과·관찰 / Observed result |
|---|---|---|---|
| 1 | **입력 준비와 녹음:** 실제 마이크를 선택하고 짧은 연주나 말소리를 녹음한 뒤 정지·저장합니다. | 커서 위치에 오디오 클립이 하나 생기고, 저장된 WAV를 재생했을 때 실제 입력이 들립니다. 클립 시작과 입력 길이가 의도와 맞습니다. | |
| 2 | **기존 트랙을 들으며 추가 녹음:** 기존 트랙 듣기를 켜고 다른 연주를 겹쳐 녹음합니다. | 녹음 중 기존 트랙이 들리고, 저장 후 새 연주가 별도 클립으로 보존됩니다. 기존 클립이 예고 없이 바뀌지 않습니다. | |
| 3 | **카운트인과 메트로놈:** 1마디 카운트인을 선택하고 메트로놈을 켠 뒤 녹음합니다. | 카운트인 후 녹음이 시작되고 박자가 명확합니다. 메트로놈과 녹음 소스가 의도하지 않게 이중 재생되지 않습니다. | |
| 4 | **모니터링과 지연:** 헤드폰으로 입력 모니터링을 켜고 연주하면서 지연을 평가합니다. 가능하면 지연 측정 방법과 값을 기록합니다. | 피드백이나 의도하지 않은 큰 왜곡이 없고, 지연을 사용 환경에 맞게 판단할 만큼 관찰합니다. 주관적 평가와 측정치를 구분합니다. | |
| 5 | **믹스 WAV 청취:** 믹스를 WAV로보내고 헤드폰과 가능하면 스피커에서 처음부터 끝까지 듣습니다. | 모든 의도된 트랙이 들리고, 무음 누락·클리핑·예상 밖의 끊김이 없습니다. 클립 경계와 페이드도 실제로 듣고 확인합니다. | |
| 6 | **저장·재열기·재생:** 프로젝트를 저장하고 SovaRoll을 다시 시작한 뒤 같은 프로젝트를 열어 재생합니다. | 트랙·클립·미디어와 재생 결과가 유지됩니다. 실제 장치의 경고·권한·연결 문제를 관찰 결과에 기록합니다. | |

## 결과 기록 규칙 / Recording rules

- 각 행에 관찰한 내용을 적고, 실패하면 재현 절차와 환경을 남깁니다.
- `통과`로 쓰는 것은 해당 행을 실제로 수행한 사람의 판단입니다. 에이전트는 문서 작성만 검증하고 하드웨어를 검증했다고 표시하지 않습니다.
- 이 체크리스트는 음악적 품질이나 프로급 저지연을 자동으로 보증하지 않습니다.
